# The Baba Recording Studio

Premium recording studio website built with React, TypeScript, and Tailwind CSS.

## About The Baba

The Baba is a professional recording studio located in Fort Lauderdale, Florida, offering:

- **Recording Sessions** - $100/hour
- **Mixing & Mastering** - $500/song  
- **Music Video Production** - $800+
- **Photography Services**
- **Commercial Production**
- **Event Coverage**

## Website Features

- 🎨 Premium dark cinematic design
- 📱 Fully responsive layout
- ⚡ Fast loading with Vite + React
- 🎯 SEO optimized with structured data
- 🔍 Local business optimization for Fort Lauderdale

## Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS 3.4
- **Build Tool**: Vite
- **Deployment**: Vercel

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

